🧭 কোন Game কীভাবে খেলবে?

1. 🧠 4 Choices
বাংলা অর্থ দেখবে → ৪টি German verb থেকে সঠিকটি বেছে নেবে।
Example: “যাওয়া” → gehen
2. ⌨️ Type It
বাংলা অর্থ/ছবি দেখে German verb নিজে টাইপ করবে।
Example: “কাজ করা” → arbeiten
3. ⚡ Speed Round
৩০ সেকেন্ডে যত বেশি পারো। প্রতিটি উত্তরে সঙ্গে সঙ্গে score ও timer দেখা যাবে।
4. 🃏 Memory Match
কার্ড খুলে German verb ও বাংলা অর্থের জোড়া মিলাবে। ভুল হলে আবার চেষ্টা করবে।
5. 🔥 Flashcard Duel
Verb + ছবি দেখবে, জোরে বলবে, Audio শুনবে, তারপর নিজে জানতাম/জানতাম না বেছে নেবে।
