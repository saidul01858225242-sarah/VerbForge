VerbForge installable PWA prototype.
Host this folder on HTTPS, open in Chrome, then choose Install app/Add to Home screen.
It supports offline practice, categories, 5 question modes, custom question count/repeat, 90% similarity, local progress, local password and reminder permission.
For reliable daily background notifications, full online competition/cloud sync, and native Android APK/AAB, a backend/native Android build is still required.
The Android/Chrome search bar cannot be hijacked by a normal PWA; Android search integration requires a native app.
